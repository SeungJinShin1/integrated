히든피스: 우리 반 보물찾기

대상: 초등학교 1~6학년

심사용 계정 안내

교사 계정 아이디{{심사용_교사ID}}
교사 계정 비밀번호{{심사용_PW}}
학생 인증번호 (6자리){{심사용_인증코드}}

※ 저학년(새싹) 모드는 로그인 없이 바로 체험할 수 있습니다.

사용 절차 요약

  • 시작 화면을 클릭해 학습을 시작합니다.
  • 모드를 선택합니다. — 히든피스 새싹(1~2학년, 로그인 불필요) / 히든피스 탐험가(3~6학년, 학생 인증번호 입력)
  • 캐릭터를 선택한 뒤 학습(보물찾기 미션)을 진행합니다.
  • 교사용 대시보드: 로그인 화면에서 교사 계정으로 로그인하면 학생 모니터링 대시보드로 이동하며, 화면 상단의 「학생 모니터링 / 게임 참여」 버튼으로 대시보드와 게임 화면을 오갈 수 있습니다.

실행 환경 안내

  • 인터넷 연결이 필요한 웹 기반 소프트웨어입니다. (별도 프로그램 설치 불필요, 웹브라우저만 사용)
  • 최신 버전의 Chrome / Edge / Safari 브라우저를 권장합니다.
  • 권장 해상도: 1920×1080 (가로 화면)

본 소프트웨어는 웹 애플리케이션으로 Next.js(프론트엔드)·FastAPI(백엔드)·Firestore(DB) 서버 환경에서 운영됩니다.
로컬 실행 방법은 source 폴더의 README_실행방법.md 참고.
